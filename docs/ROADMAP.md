# Roadmap

Rough order. Dates are targets, not promises.

**Now (v0.1, October 2026).** Dashboard, template in and out, engine validated against the original spreadsheet, export to Excel, CSV and print.

**By end of 2026.** Verify every emission factor against its primary source and record the licence. Move constants into the factor library. Reusable Python package with the same engine and the same tests, so both implementations must agree on shared example files.

**Early 2027.** Missing categories (downstream transport, leased assets, renewable energy and market-based Scope 2). Per-employee and per-m² intensity in the template and dashboard. Decarbonisation scenarios: apply reduction measures to an inventory and show the effect against a baseline year.

**Spring 2027.** Use on real projects (kept private, reported only in aggregate), user documentation, and a paper describing the software.
